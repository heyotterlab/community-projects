# OtterLab Community Projects 🦦

> Technology is better when we build it together.

A friendly place to share HomeLab and vibe-coding projects, from a first Expense Tracker to a rack in a closet. Beginners welcome.

Part of the [OtterLab](https://otterlab.click) community. Chat with us on [Discord](https://discord.gg/nRgB8ARJ66).

## Share your project

Pick whichever is easiest:

1. **Discord:** post a Project Card in `#project-showcase`. No GitHub needed.
2. **Issue:** open a [Share a project](../../issues/new?template=share-a-project.yml) issue.
3. **Pull request:** copy [`projects/_template/README.md`](projects/_template/README.md) to `projects/<your-project>/README.md` and open a PR. The [contributing guide](CONTRIBUTING.md) walks through it step by step.

Unfinished and messy is welcome. A short card is a good card.
