# Security

Most of what's in this repo is community projects, written by members. We take two kinds of problems seriously: **leaked secrets** and **unsafe project advice**.

## Found a leaked password, key, token or private info?

1. **Don't repeat it** in a public issue, comment or Discord message.
2. Tell us privately: email conduct@otterlab.click, or message a moderator on Discord.
3. We'll remove it and let the author know, kindly.

**If it's yours:** rotate or revoke it with whoever issued it, right now. Deleting a file or a post doesn't undo it, because bots scrape fast and Git keeps history.

## Found a vulnerability in a project or in this repo?

Email conduct@otterlab.click with what you found and where. Please give us a reasonable chance to fix it before sharing it publicly. We'll reply within a week. We're a small community project with no bug bounty, but we'll gladly credit you.

## What we don't do

We don't run security audits of members' projects. Anything here is shared as-is by its author. Before you run something you found, read it, and don't run anything you don't understand on a machine that matters. Back up first.

## Supported versions

This repository holds documentation and examples, not a product with versions. The latest `main` branch is what we maintain.
